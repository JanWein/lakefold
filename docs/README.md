# Documentation map

## Using tidyweave

Start at [Get started](https://janwein.github.io/tidyweave/articles/get-started.html).
The five executable lessons are the canonical beginner path. Use
[Learn](https://janwein.github.io/tidyweave/articles/learn.html) for additional tasks,
[Help](https://janwein.github.io/tidyweave/articles/troubleshooting.html) for failures,
and the [reference](https://janwein.github.io/tidyweave/reference/index.html) for arguments.

The website is generated from README, `vignettes/`, roxygen function help and
`_pkgdown.yml`. Edit those sources, not generated HTML. Files in this directory
are operating notes, links and dated development records, not a competing tutorial.

# Quality and history

The canonical, executable guides are:

- [Quality gates](https://janwein.github.io/tidyweave/articles/quality-gates.html):
  start with one rule, then add contracts, reference checks or pointblank.
- [Quality and history](https://janwein.github.io/tidyweave/articles/quality-history.html):
  diagnose attempts, retain evidence and reproduce pinned releases.

Edit the corresponding [quality-gates.Rmd](../vignettes/quality-gates.Rmd) and
[quality-history.Rmd](../vignettes/quality-history.Rmd) sources to update these
tutorials. This index does not duplicate their examples.
